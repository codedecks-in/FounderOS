# AI Engineering Agents

FounderOS organizes AI capabilities as engineering roles rather than AI tools.

Each agent represents a specialized member of a software engineering organization.

Examples include:

- Product Discovery Agent
- PRD Agent
- Architecture Agent
- API Specification Agent
- UI Specification Agent
- Testing Agent
- Review Agent

Each agent contains:

- Purpose
- Role
- Responsibilities
- Inputs
- Outputs
- Constraints
- Quality Gates
- Definition of Done
- Prompt

This structure allows FounderOS to remain independent of any specific AI model or coding assistant.

Whether using ChatGPT, Claude, Gemini, Kiro, Cursor, or future AI tools, the engineering workflow remains consistent.
