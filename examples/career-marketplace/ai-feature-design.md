# AI Feature Decision — Career Marketplace MVP

**Status:** Not applicable to MVP; reevaluate only after a product decision  
**Inputs:** [Discovery](discovery.md), [PRD](prd.md)  
**Feeds into:** Future product discovery if AI scope is proposed

Discovery explicitly excludes AI-generated assessments or feedback from the MVP. The current marketplace can validate expert discovery, booking, payment, and session outcomes without AI. No model, prompt, data processing, or AI evaluation is authorized by this reference design.

If a future feature is proposed, define user value, deterministic alternative, permitted data, output contract, human oversight, safety limits, evaluation set, and cost/latency budgets using `templates/ai-feature-design.md` before implementation. Any use of private seeker or expert data requires separate privacy and security review.
